# 구현 과제 AI 사용 기록

## 2026-11-11 · Codex · 구현 전 설계 검토

이번 요청에서 구현 과제의 설계에 사용한 문장을 원문에서 발췌했다.

> 구현 과제의 평가 기준을 보고, 어떻게 구현하면 좋을지 의견 제시해줘.

> 공고를 분석해서 "내가 특히 신경써야 할 점이 무엇인지" 얘기하고, 프로젝트에 어떻게 적용할 수 있을지 알려줘.

검진 API 계약을 보존하는 방법, 측정값과 참고 기준을 연결하는 방법, 로컬 모델의 역할과 후보 모델 비교 방식을 검토했다. 이 단계의 산출물은 [구현 및 검증 계획](README.md)이다. 모델 선택과 성능 수치는 실제 실행 결과로 결정한다.

이후 개발 중 AI를 사용한 항목에는 당시 입력한 프롬프트 원문, 적용한 제안, 수정한 내용과 검증 결과를 기록한다. 앱이 실행 중 Ollama에 전달하는 프롬프트는 해당 소스 파일에서 확인할 수 있도록 연결한다.
