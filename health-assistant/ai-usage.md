# 검진 비서 개발에 AI를 어떻게 활용했습니까?

지원자는 모델 이름을 가린 실제 화면 답변들을 직접 대조하여 프로젝트의 기본 LLM을 최종 결정했습니다. AI 도구인 Codex는 Mock 검진 API와 LangGraph 파이프라인 구현, 테스트 코드 작성, 평가용 질문 및 기대값(Golden Set) 생성, 같은 질문으로 두 모델의 답변과 Qwen 프롬프트 변경 전후의 답변을 수집하는 작업을 분담했습니다.

## 구현과 검증 계획

먼저 NestJS 환경에서 과제 예시와 같은 구조의 JSON을 반환하는 검진 조회 API를 만들고, 질문 답변 API가 내부 HTTP 통신으로 검진 기록을 조회하도록 파이프라인을 구축했습니다. 이어서 고정된 Mock 응답을 사용하는 단위 및 통합 테스트를 작성하여 미등록 환자(404 에러), 검진 이력이 없는 환자, 비정상적인 모델 응답에 대한 예외 처리를 검증했습니다. 그 후 실제 로컬 Ollama 환경에서 후보 모델들의 답변 품질을 비교해 기본 모델을 확정하고, 선정된 모델에서 프롬프트 예시를 개선하며 품질 변화를 단계적으로 측정했습니다. [테스트와 실행 방법](README.md#검증) · [실제 모델 평가 방법](evaluation/PROTOCOL.md)

## 결과를 바꾼 개발 프롬프트

아래 인용은 지원자가 Codex에 보낸 요청 중, 아키텍처 및 품질 개선 결정과 직접 관련된 문장을 발췌한 것입니다.

**1. 틀린 답과 채점기가 거절한 답을 구분했습니다.**

> 실패한 12건 중에 채점기가 빡빡해서 틀린 처리된 건 몇 건이고 실제로 잘못 답한 건 몇 건이야? 원응답이랑 검진표를 대조해보고, 서버 검증을 최소화하면서 항목 선택이나 해석 오류를 줄일 방법을 제안해줘.

당시 사용하던 자동 채점기는 골밀도 측정값이 같아도 ‘T-score는 -0.8’처럼 한국어 조사가 붙었다는 이유만으로 오답으로 거절했습니다. 이러한 분석을 바탕으로 현재 서버는 엄격한 텍스트 매칭 대신 JSON 문법 형식과 인용한 출처의 실재 여부만 검증하도록 역할을 축소했습니다. 설명문 속 세부 수치와 의학적 판정의 정합성은 사후 평가 단계에서 검진표 기준과 대조해 검증하도록 책임을 분리했습니다. [재채점 기록](evaluation/results/final/reading-regrade.json) · [서버 검증을 줄인 근거](docs/adr/002-answer-validation.md)

**2. 기본 모델은 화면에 표시된 답변을 보고 정했습니다.**

> 이 리뷰가 시사하는 것을 알려 주고, md 파일에 기록해줘. 그리고 어떤 모델을 선택하는 게 좋을지 의견을 제시해줘.

두 모델 모두 기대한 출처를 14문항 중 10번씩 올바르게 선택했습니다. 그러나 간 기능 수치를 물었을 때 Qwen은 환자의 실제 측정값인 AST 30 U/L와 ALT 28 U/L를 명시한 반면, Llama는 수치 없이 검사 목적과 기준치만 설명했습니다. 지원자가 두 모델의 답변 14쌍을 모델 이름을 가리고 블라인드로 직접 비교한 결과, Qwen 9건, Llama 3건, 동률 2건으로 평가되어 Qwen 2.5 7B를 최종 선택했습니다. [블라인드 리뷰와 모델 선택](evaluation/RESULTS.md#qwen을-선택한-이유)

**3. 모델을 정한 뒤에는 예시의 효과를 따로 확인했습니다.**

> 운영 그래프와 JSON·출처 검증은 유지하고, 프롬프트 예시 보완과 자연어 문자열 채점 제거만 적용해. 기존 질문으로 before-after 비교해서 결과도 남겨줘.

전체 요약과 콜레스테롤에 관한 문답 예시를 실제 출력 형태인 JSON 포맷으로 보여주고, 성별 정보가 없어 의학적 판정을 내릴 수 없는 혈색소 검사는 판정을 보류하도록 안내하는 예시를 추가했습니다. 동일한 평가 도구로 비교한 결과, 모델을 호출한 19개 문항 중 기대한 검사일과 항목을 올바르게 인용한 횟수는 14건에서 18건으로 늘었습니다. 다만 올바른 출처를 인용하고도 혈압 판정을 잘못 설명한 답변은 여전히 과제로 남았습니다. [같은 질문에서 달라진 답변](evaluation/results/prompt-examples-2026-11-13/comparison.md)

## 최종 운영 프롬프트

검진 비서는 모델에 아래 시스템 지시를 전달합니다.

```text
질문에서 지정한 시점의 기록을 사용하고, 시점 언급이 없으면 최근 기록으로 답하세요. sources에는 실제 사용한 검사일/검사명만 넣고 해당 기록이 없으면 빈 배열을 반환하세요.
전체 요약은 BMI·공복혈당·혈압, 콜레스테롤 전반은 기록에 있는 총콜레스테롤·HDL·LDL을 설명하세요.
한국어 한두 문장으로 질문한 항목의 검사일·측정값·단위와 해당 행의 검진표 판정을 그대로 전하세요. 분류 보류면 측정값과 보류 이유만 답하세요.
생활 안내는 필요할 때만 짧게 덧붙이고 질환 확정이나 복약 변경은 피하세요.
```

이 지시와 함께 세 가지 문답 예시, 해당 환자의 검진 기록, 질문을 순서대로 전달합니다. [예시와 입력을 만드는 코드](src/assistant/model.ts) · [실제 질문별 입력과 답변 전문](evaluation/results/prompt-examples-2026-11-13/after/qwen2.5_7b.jsonl) · [출력 스키마와 생성 설정](evaluation/results/prompt-examples-2026-11-13/after/prompt-protocol.json)
