# 모델 선택과 응답 품질

**기본 모델은 Qwen 2.5 7B입니다.** 두 모델에 같은 질문을 했을 때, Qwen은 AST·ALT처럼 환자가 물은 검사 수치를 직접 제시했습니다. 이후 Qwen의 프롬프트 예시를 보완해 검사일과 항목 선택이 나아졌지만, 설명에서 검진표와 다른 판정을 내리는 오류는 남았습니다.

## Qwen을 선택한 이유

Codex가 과제 검진표를 바탕으로 평가 질문과 기대값을 작성했습니다(Golden Set). 기본 평가 14문항으로 두 모델의 답변을 생성하고, 지원자 한 명이 모델 이름을 가린 상태에서 질문마다 어느 답변이 더 적합한지 직접 선택했습니다.

| 같은 14문항에서 확인한 항목                 | Qwen 2.5 7B | Llama 3.1 8B |
| ------------------------------------------- | ----------: | -----------: |
| 블라인드 비교에서 선택한 답변 수 (동률 2건) |           9 |            3 |
| 기대한 검사일·항목과 출처가 일치한 요청 수  |          10 |           10 |

AST·ALT를 물었을 때 Qwen은 환자의 측정값 30·28 U/L를 답했고, Llama는 검사 용도와 참고 기준만 설명했습니다. 과거 공복혈당 질문에서는 Llama가 105 mg/dL를 답했고 Qwen은 출처를 비워 화면에 특정 불가 안내가 나왔습니다. 두 모델의 출처 일치 건수가 같아, 실제로 질문한 수치를 알려주는지와 블라인드 비교 결과를 모델 선택에 반영했습니다. [자동 집계](results/cited-records/summary.json)

두 모델은 같은 질문과 옵션으로 비교했습니다. Qwen과 Llama의 파라미터 수는 각각 7.6B와 8.0B로 과제 상한인 12B 이하입니다. 이 비교는 **예시 변경 전의 사용자 선호**를 측정했습니다. 선택된 답변에도 LDL 판정 오류가 있었습니다. [블라인드 선택과 답변 대조](results/cited-records/human-review.md) · [모델과 실행 환경](results/cited-records/manifest.json)

## JSON 예시를 바꾼 결과

짧은 예문만 주었을 때는 측정값이나 항목이 빠졌습니다. 두 기본 문답을 실제 출력과 같은 JSON으로 바꾸고, 성별 정보가 없을 때 혈색소 판정을 보류하는 예시를 추가했습니다. 기본 14문항에 과제 예시·API 처리·간접 질문 7개를 더해, 같은 21문항을 변경 전후 한 번씩 실행했습니다. 빈 이력과 미등록 환자 2건에서는 모델을 호출하지 않았습니다.

| 관찰값                                     | 변경 전 | 변경 후 |
| ------------------------------------------ | ------: | ------: |
| 기대한 검사일·항목과 출처가 일치한 요청    |   14/19 |   18/19 |
| 콜레스테롤 답변 / 최근 검진 요약의 문장 수 |   4 / 7 |   2 / 3 |
| 전체 21개 답변의 문장 수 합계              |      40 |      40 |

혈색소 13.2 g/dL에 근거 없이 정상이라고 답하던 모델이 성별 정보가 없어 판정을 보류한다고 설명했습니다. 반면 LDL 150 mg/dL에는 ‘정상’과 ‘분류 보류’를 함께 썼고, 혈압 118/92의 간접 질문에는 올바른 기록을 인용하고도 정상(A)이라고 설명했습니다.

**18/19는 기대한 검사일과 항목을 선택한 횟수입니다.** 설명에 담긴 수치와 판정은 검진표와 따로 대조했습니다. 이미 본 질문을 사용했고 세 질문은 새 예시에도 들어 있습니다. 변경 후 답변을 다시 블라인드 평가하지 않았습니다. 다음 검증에서는 예시에 없는 표현으로 같은 수치를 물어보고 출처 선택과 판정 오류를 따로 확인할 필요가 있습니다. [변경 조건과 원응답](results/prompt-examples-2026-11-13/comparison.md) · [평가 방법](PROTOCOL.md)
