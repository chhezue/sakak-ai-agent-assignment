# 모델 선택과 응답 품질

본 프로젝트의 기본 LLM은 Qwen 2.5 7B입니다. 모델을 선정하는 과정에서는 지원자가 직접 비교한 최종 화면 답변 14쌍의 블라인드 평가 결과를 활용했습니다. 이후 프롬프트를 개선하는 단계에서는 동일한 Qwen 모델에 같은 21개 평가 문항을 다시 입력하여 예시 변경 전후의 결과를 비교했습니다.

## Qwen을 선택한 이유

초기 구현 단계에서는 Llama가 첫 번째 출력의 규칙 검사를 더 높은 비율로 통과했고 응답 속도도 빨랐습니다. 첫 답변을 다시 채점했을 때 Llama는 20/24건, Qwen은 16/24건을 통과했습니다. 그러나 이후 서버의 응답 검증 방식을 단순화하면서, 규칙 통과율 대신 사용자의 화면에 실제로 표시되는 설명의 적절성을 기준으로 모델을 다시 평가하고 선정했습니다. [초기 비교 조건과 결과](results/final/human-review.md)

평가용 데이터셋(Golden Set)은 Codex가 과제 검진표를 바탕으로 질문과 기대값을 작성했습니다. 기본 평가 14문항에 대해 두 모델의 답변을 수집한 뒤, 지원자 한 명이 모델 이름을 가린 상태에서 질문별로 어느 답변이 더 적합한지 블라인드로 직접 선택했습니다.

| 같은 14문항에서 확인한 항목                 | Qwen 2.5 7B | Llama 3.1 8B |
| ------------------------------------------- | ----------: | -----------: |
| 블라인드 비교에서 선택한 답변 수 (동률 2건) |           9 |            3 |
| 기대한 검사일·항목과 출처가 일치한 요청 수  |          10 |           10 |

두 모델의 답변을 비교했을 때, 간 기능 수치(AST·ALT) 질문에서 Qwen은 환자의 실제 측정값인 30 U/L와 28 U/L를 제시한 반면, Llama는 수치 제시 없이 검사 목적과 기준치만 설명했습니다. 반대로 과거 공복혈당 질문에서는 Llama가 105 mg/dL를 명시해 정답을 맞혔으나, Qwen은 출처를 비워 화면에 특정 불가 안내 문구가 표시되었습니다. 기대한 출처와의 일치 건수는 두 모델 모두 10건으로 동일했기 때문에, 질문에 해당하는 구체적인 수치를 실제로 알려주는지와 블라인드 선호도 평가 결과를 모델 선정의 결정적 근거로 삼았습니다. [자동 집계](results/cited-records/summary.json)

두 모델은 동일한 평가 질문과 파라미터 옵션으로 실행해 비교했습니다. Qwen과 Llama의 파라미터 수는 각각 7.6B와 8.0B로 과제 상한인 12B 이하 조건을 충족합니다. 다만 이 평가는 **프롬프트 예시를 변경하기 전 상태에서 사용자의 선호**를 측정한 결과입니다. 또한 지원자가 더 낫다고 선택한 답변 중에서도 LDL 판정 오류가 포함되어 있는 한계가 관찰되었습니다. ## JSON 예시를 바꾼 결과

초기에 짧고 단순한 예시만 제공했을 때는 모델이 답변에서 측정값이나 검사 항목 자체를 누락하는 경향이 있었습니다. 이에 따라 두 가지 기본 문답을 실제 출력 규격과 동일한 JSON 구조로 변경하고, 성별 정보가 부족할 때 혈색소 판정을 보류하도록 안내하는 예시를 추가했습니다. 기본 14문항에 과제 예시·API 처리·간접 질문 7문항을 더한 총 21개 문항으로 예시 변경 전후를 각각 1회씩 실행했습니다. 검진 이력이 비어 있거나 미등록된 환자 2건은 서버에서 모델을 호출하지 않고 종료되었습니다.

| 관찰값                                     | 변경 전 | 변경 후 |
| ------------------------------------------ | ------: | ------: |
| 기대한 검사일·항목과 출처가 일치한 요청    |   14/19 |   18/19 |
| 콜레스테롤 답변 / 최근 검진 요약의 문장 수 |   4 / 7 |   2 / 3 |
| 전체 21개 답변의 문장 수 합계              |      40 |      40 |

프롬프트 예시를 개선한 뒤, 혈색소 13.2 g/dL 질문에 대해 이전에는 근거 없이 정상이라고 단정하던 모델이 성별 정보가 없어 판정을 보류한다고 올바르게 설명했습니다. 반면 LDL 150 mg/dL 질문에서는 한 답변 안에서 ‘정상’과 ‘분류 보류’라는 모순된 표현을 함께 썼고, 혈압 118/92에 대한 간접 질문에서는 올바른 검진 기록을 출처로 인용하고도 정상(A)으로 잘못 판정했습니다.

**위 표의 18/19는 기대한 검사일과 항목을 올바르게 선택한 횟수를 측정한 수치입니다.** 설명문에 담긴 구체적인 수치와 의학적 판정의 정합성은 검진표 기준과 별도로 대조했습니다. 이번 평가는 이미 검토한 질문을 사용했고 그중 3개 질문은 새 프롬프트 예시에도 포함되어 있었습니다. 아울러 예시 변경 후의 답변에 대해서는 추가적인 블라인드 평가를 진행하지 않았습니다. 따라서 다음 검증에서는 예시에 포함되지 않은 새로운 표현으로 동일한 수치를 질문하고, 출처 선택의 정확도와 판정 오류를 분리하여 검증할 필요가 있습니다.
