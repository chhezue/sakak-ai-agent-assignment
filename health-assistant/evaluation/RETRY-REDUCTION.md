# 같은 항목을 다시 누락한 재생성 요청

초기 Llama 구현은 답변에 근거가 빠지면 한 번 더 생성했습니다. 최근 검진 요약과 두 검진의 혈당 비교에서 교정 후에도 같은 항목이 빠졌고, 결국 서버가 검진값으로 대체했습니다. 이 유형만 재생성을 생략해 호출 비용을 비교했습니다.

같은 17문항을 조건별 두 번 실행했습니다. 모델 경로 24건에서 생성 호출은 **28회에서 24회**로 줄었고, 영향을 받은 네 요청의 평균 시간은 8.65초에서 5.96초로 줄었습니다. 요청 ID를 제외한 최종 응답은 제어 경로를 포함한 34건 모두 같았습니다. 반면 전체 모델 경로의 p95는 9.00초에서 9.82초로 늘었습니다.
