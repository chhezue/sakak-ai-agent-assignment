# 서버에 있는 값을 모델이 다시 생성할 필요가 있는지 비교했습니다

초기 Llama 응답에는 근거 ID와 설명뿐 아니라 측정값·단위·분류가 별도 필드로 들어 있었습니다. 서버가 이미 가진 세 필드를 없애고 출력 형식 안내를 함께 바꿨습니다.

같은 17문항을 조건별 두 번 실행했습니다. 모델 호출 24회에서 출력 토큰 합계는 **1,832개에서 1,624개**로 줄었습니다. API 지연 중앙값은 4.453초에서 3.872초로 줄었지만 p95는 8.589초에서 8.755초로 늘었습니다. 두 조건 모두 재생성은 없었습니다.

당시에는 중복 필드를 제거한 형식을 채택했습니다. 스키마와 안내를 동시에 바꿨으므로 어느 하나의 효과로 분리할 수 없으며, 이 수치는 현재 Qwen의 성능 측정값이 아닙니다. [요청별 측정값](results/output-reduction/comparison.json) · [현재 출력 계약](../docs/decisions.md)
