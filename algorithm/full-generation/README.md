# 전체 항 생성

[구현](solution.ts)은 이전 항을 왼쪽부터 읽으며 연속된 숫자의 개수와 그 숫자를 붙입니다. 예를 들어 `111221`은 `111 | 22 | 1`로 묶이므로 다음 항은 `31 | 22 | 11`, 즉 `312211`입니다. 떨어져 있는 같은 숫자는 따로 셉니다.

첫 항 `1`에서 이 변환을 n−1번 반복합니다. 마지막 항의 길이가 M일 때 0부터 세어 M/2−1, M/2 위치의 문자를 반환합니다. 작은 입력에서 생성 과정과 답을 눈으로 확인할 수 있어 [구간 분할과 길이 DP](../segment-length-dp/README.md)의 대조 기준으로 사용했습니다.

**복잡도:** i번째 항의 길이를 Mᵢ라고 하면 각 항을 한 번씩 읽으므로 시간은 O(Σ Mᵢ), 이전 항과 다음 항을 보관하는 공간은 O(max Mᵢ)입니다. 50항은 894,810자지만 51항은 1,166,642자입니다. 이 구현은 한 항이 100만 자를 넘으면 중단합니다.

`algorithm` 디렉터리에서 `npm ci` 후 `npm run test:full-generation`으로 [묶음 규칙과 입력 경계](solution.test.ts)를 확인합니다. [두 풀이의 성능 비교](../README.md#35항은-전체-생성이-빨랐고-99항은-구간-분할로-풀었습니다)
